# Controles e acessibilidade

## Teclado

| Ação | Padrão |
|---|---|
| Mover | WASD ou setas |
| Correr | Shift |
| Interagir | E |
| Atacar | J ou Espaço |
| Técnicas | Z e X |
| Esquivar | Q |
| Especial | K |
| Trocar integrante | 1, 2 e 3 |
| Usar fita de cura | R |

Os menus aceitam navegação por setas, confirmação e retorno. A tela de controles permite remapear comandos; as dicas acompanham o mapeamento salvo.

## Controle

| Ação | Mapeamento PlayStation |
|---|---|
| Mover / correr | Analógico ou direcional / L2 |
| Interagir / confirmar | ✕ |
| Atacar / esquivar | □ / ○ |
| Técnicas | L1 / R1 |
| Especial | R2 |
| Trocar integrante | △ |
| Pausa | Options |
| Usar fita de cura | Share / Create |

São aceitos controles compatíveis com a Gamepad API. Com dois controles, o segundo jogador assume outro integrante vivo da formação; ambos compartilham a câmera.

## Toque e leitura

Celulares e tablets recebem controles de toque. As posições podem ser ajustadas nas opções de controles. Retrato e paisagem têm configurações independentes.

As opções de leitura incluem velocidade do texto, avanço automático e histórico. O histórico bloqueia comandos de avanço da conversa enquanto está aberto. Avisos visuais e opções de movimento reduzido permanecem disponíveis nas configurações do jogo.
