# TORII & HUTUKARA — A Última Frequência

Projeto de RPG em HTML Canvas. **Build jogável de referência: 1.1.2 (pré-alpha).**

A build original possui aproximadamente 40 MB, incluindo CSS, JavaScript e imagens embutidas. O pacote de arquivos completo foi preparado separadamente para preservar os arquivos originais, mas a sincronização dos arquivos de grande porte com este repositório ainda está pendente.

## Organização prevista
- `builds/1.1.2/`: HTML original completo sem alterações.
- `production/chapter-03/`: diálogos, missões, roteiro, direção de arte e imagens de referência.
- `docs/`: análise técnica e hashes para verificação.

**Importante:** O material do Capítulo 3 é documentação de produção e não faz parte da versão jogável atual.

Assim que o pacote completo for enviado ao repositório, este README poderá documentar o processo de execução e desenvolvimento.
