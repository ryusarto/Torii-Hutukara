# Site oficial do álbum — Torii & Hutukara

O portal está em `web/album/` e é publicado em `/Torii-Hutukara/album/` pelo workflow `Publish playtest`. A raiz `/Torii-Hutukara/` continua sendo o jogo e não é modificada.
